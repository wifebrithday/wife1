CARA MENGGUNAKAN
1. Buka index.html di browser.
2. Untuk musik, masukkan file musik milikmu bernama "musik.mp3" ke folder yang sama.
3. Untuk foto, kamu bisa mengganti bagian placeholder .photo dengan:
   <img src="foto1.jpg" alt="Kenangan">
   lalu simpan foto1.jpg di folder yang sama.
4. Edit nama, tanggal, cerita, dan surat langsung di index.html.
